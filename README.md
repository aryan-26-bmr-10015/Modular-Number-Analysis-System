# Number Property Checker

This project is a Python-based menu-driven program that checks whether a given number is:

- Armstrong number

- Palindrome number

- Happy number

- Harshad number

It also allows the user to check all properties for the number at once.

## Features

- Check Armstrong number

- Check Palindrome number

- Check Happy number

- Check Harshad number

- Check all conditions together

- command-line interface

## Requirements

- Python 3.x

## How to Run

1. Open the project folder in your terminal.

2. Run the script:

```bash

python main.py

```

## How It Works

When the program starts it asks the user to enter a number and then displays a menu with options:

1. Check Armstrong

2. Check Palindrome

3. Check Happy

4. Check Harshad

5. Check All

6. Exit

The user selects an option. The result is printed based on the selected number.
