# Problem Statement

The project wants to build a Python-based number checking system that helps people find out if a number is an Armstrong number, a palindrome, a happy number or a Harshad number. Many people need fast. Correct answers for these math properties but checking them by hand can take a long time and have mistakes. This program gives an fast way to check these things automatically.

# Scope of the Project

This project is about making a simple command-line app that:

- takes a number from the person using it

- checks the number for math properties

- lets the person pick one check or do all checks at the same time

- keeps working until the person decides to stop

The project is only, about checking number properties and making a user-friendly menu-based system. It does not include an interface or storing data in a database.

# Target Users

The system is made for:

- students who are learning Python and number theory

- people who want to quickly check math properties of numbers

- new programmers working on small real-life projects

- learning places where simple computer tools are helpful

# High-Level Features

- Check if a number is an Armstrong number

- Check if a number is a palindrome

- Check if a number is a happy number

- Check if a number is a Harshad number

- Let the user check all properties for the same number together

- Give a simple menu-based system

- Keep asking for input until the user wants to stop the program
